## 六种界面语言

右上角 Language 选择中文、English、Français、日本語、Deutsch 或 Русский。主界面与色卡窗口都可切换，照片、取样位置、色彩空间与拟合结果不变。语言偏好保存在本机用户配置目录，应用重新启动后仍然保留。翻译目录为 `jc_colorlab/static/locales/catalog.json`，无需联网。源码开发文档目前以中文为主，色卡位图保留固定技术标记，避免语言影响识别或数字参考。

## 白平衡灰条

标题右侧的长条中性灰适合从照片中截取或用白平衡工具取样。优先取中部，避开边缘、反光和刷新条纹。灰条按所选色卡空间定义约 18% 线性亮度，精确量化值随参考数据一同导出。它不参与色块拟合，也不代表屏幕经过仪器测量。拍摄成对风格照片时保持同一白平衡设置。

## 高像素照片

- 单张照片：最多 240,000,000 像素。
- 当前会话的基准、风格和测试照片：合计最多 240,000,000 像素。
- 单个上传文件：最多 2GiB。
- 两张 120MP 可以同时载入；单张 240MP 会用完会话预算。替换现有照片按新组合重新计算。

102MP 文件不再被旧上限拦截。实际 RAW 相机支持依赖 LibRaw，容量放宽不等于新增所有相机型号支持。内部保留浮点图像，240MP 的 RGB 图像本体约需 2.88GB；解码和预览还需要额外内存。两张 120MP 合成 JPG 的本机验证峰值约 5.1GB，复杂 RAW 或跨空间转换可能更高。TIFF 按条带处理与写出，仍需足够磁盘空间。

## 平台

macOS Apple Silicon 有本地验证。Windows x64 包在 Mac 上组装，尚未实机测试；作者目前只有 Mac，不能提供 Windows 日常维护。保留源码与跨平台 CI 供社区验证。
