## 中文

JC ColorLab 第二版：屏幕相对校色与相机风格提取工具。

- 中文、English、Français、日本語、Deutsch、Русский六语界面与语言记忆。
- 色卡标题右侧新增长条中性灰，方便白平衡取样；约 18% 线性亮度的数字参考。
- 单张照片与当前会话合计上限均提升至 240MP，单文件最多 2GiB；优化大图处理与 16 位 TIFF 分块导出。
- 支持 RAW/JPG、自动色卡识别、手动取样调整、多色域及 CUBE/XMP 导出。
- 修复 Windows 默认编码导致页面无法打开的问题。

**下载：** Apple Silicon Mac 请选择 `macOS-arm64.zip`；Windows x64 请选择 `Windows-x64-experimental.zip`。完整解压后运行。另附源码与 SHA-256 校验清单。安装包由本次 GitHub Actions 在对应平台构建，内附构建环境与源码提交记录。

**验证与限制：** 167 项 Python 测试与 8 项 JavaScript 检查；只有两平台检查与打包成功后才会公开发布。本机已验证两张各 120MP 的合成 JPG 同时载入，以及 120MP TIFF 导出。Mac 应用未经 Apple 开发者签名或公证。Windows 包虽通过云端测试和打包，仍未经过真实 Windows 电脑的交互测试；作者目前只有 Mac，无法进行 Windows 日常实机测试与维护。屏幕参考不是仪器测量的绝对色准；XMP 的 Adobe 宿主验证尚未完成。

## English

JC ColorLab v0.2.0 adds six interface languages, a neutral white-balance strip, and support for up to 240MP per image and across all loaded photos, with a 2GiB file limit. Large-image processing and 16-bit TIFF export use bounded processing blocks. A Windows default-encoding page-loading issue was fixed before release.

Choose `macOS-arm64.zip` for Apple Silicon Macs or `Windows-x64-experimental.zip` for Windows x64. Extract the entire package before launching. Source and SHA-256 checksums are also attached. Packages are built on their respective platforms by GitHub Actions and include dependency and source-commit records.

Validation includes 167 Python tests and 8 JavaScript checks; publication requires successful tests and packaging on both platforms. Local macOS checks included simultaneous loading of two synthetic 120MP JPEGs and a 120MP TIFF export. The Mac app is not Apple Developer-signed or notarized. **Windows remains experimental: CI passed, but interactive use on real Windows hardware has not been tested, and the author currently only has a Mac for testing and maintenance.** Calibration is screen-relative, not instrument-measured absolute accuracy. Adobe-host validation of XMP remains pending.
