# v0.1.0 alpha 验证记录

核对日期：2026-10-29（America/Toronto）。作者署名：J.C. Lu。

| 检查 | 结果与范围 |
|---|---|
| 自动测试 | macOS arm64 / Python 3.12：157 项通过。涵盖五空间数学转换、ICC、高位深图像、RAW 固定参数、XMP/CUBE、色卡识别、拟合与本机接口 |
| JPG 定位 | 默认 376 色；1920×1080、JPEG 4:2:0、质量 60/80/95，以及透视和模糊的合成测试；至少三枚一致标记才自动定位 |
| 界面操作 | 本机浏览器检查：P3 色卡 + ProPhoto 工作空间、校色及风格拟合、376 个取样点、工作域外参考排除与质量提示 |
| 真实 RAW | 一张 8000×5320、42.56MP DNG；sRGB 与 ProPhoto 显影均成功，像素有限；16 位 TIFF 往返最大误差约 7.63×10⁻⁶（半个码值） |
| Mac 独立应用 | PyInstaller arm64 应用成功启动；五工作空间分别完成合成风格拟合及 CUBE、XMP、16 位 TIFF 导出。逐一检查 TIFF ICC 名称与所选空间一致 |
| Windows 包静态检查 | 177 个 PE 文件均为 AMD64；补齐 LibRaw 需要的 MSVCP140.dll 标准文件名；未解析项只剩 Windows 系统 DLL / API set。静态检查不验证实际装载和运行 |
| XMP 编码 | 独立解码验证 32³ 节点、通道顺序、压缩、摘要和颜色空间字段；未在 Adobe 应用实测导入与渲染 |

Windows 便携包在 Mac 上组装，**没有 Windows 实机运行结果**。J.C. Lu 目前仅有 Mac，暂不测试与维护 Windows。Mac 包未经 Apple 开发者签名或公证，也没有进行 Intel Mac 测试。

合成测试与软件数字一致性不能证明屏幕物理色准，不能证明映射适用于所有相机、光源与真实场景。没有测色仪验证，没有逐厂商/逐机型 RAW 样本覆盖。具体 RAW 入口与限制见 [RAW_SUPPORT.md](RAW_SUPPORT.md)。

真实 DNG 来源为 Adobe 官方示例，仅用于本地验证，未随源码或应用包分发。合成示例在软件中明确标记，不作为真实相机校准测量。
