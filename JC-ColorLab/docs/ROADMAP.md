# 迭代路线

作者：**J.C. Lu**。本文件区分当前能力和未来计划；计划不代表已实现或已承诺发布日期。

## v0.1.x：把实验过程做实

- 完成不同机型真实 RAW、不同浏览器与显示器配置的验证记录。
- 扩充异常定位、非均匀照明、摩尔纹、剪切和覆盖不足的测试样例。
- 根据实际拍屏照片调整色卡密度、采样半径和误差报告。
- 验证 macOS 安装包在另一台干净机器上的启动；建立签名、公证与可复现构建记录。
- 通过社区协作执行 Windows 构建和实机验收；作者目前无法承担 Windows 日常维护。
- 完成 Adobe 宿主中 XMP 的导入、数值一致性与兼容性验证。

## v0.2：项目与工作流

- 会话工程保存/恢复、原图指纹、明确的 RAW 参数与配置版本追踪。
- 多张色卡联合拟合、跨曝光验证、重复样本一致性分析。
- 批量应用和任务取消，改善大图内存使用与处理速度。
- 支持用户提供、具有合法来源和测量条件的实体色卡参考数据。
- 以测试数据确定是否增加可选拟合模型，不靠更高模型复杂度掩盖采样问题。

## 后续研究：可追溯的物理参考

- 导入测色仪实测 XYZ/Lab，明确观察者、光源、显示条件和不确定度。
- 显示器配置与浏览器显示链路检查；通过实测确认 P3/Adobe RGB 目标覆盖与色准，不只依据系统配置或屏幕规格推断。
- 扩展 HDR/场景域前建立明确的曝光、负值、超白值与显示变换约定；当前 ACEScg 不代表已实现完整 ACES 流程。
- 对多光源、不同相机、不同屏幕光谱进行独立验证。
- 研究真正的相机配置文件工作流（DCP/ICC），与显示参考 CUBE 明确分开。
- 研究在多张独立图像上识别相机风格；对局部/语义处理明确给出无法用 3D LUT 表达的部分。

## 发布约定

每个版本保留版本号、日期、已增加/修复内容、迁移注意事项、已知限制与测试环境。色卡定义或模型格式改变时升级其独立版本，避免旧照片被新定义错误解释。没有实机测试的平台始终标注“未测试”，CI 成功不能替代图形界面或物理色准验证。
