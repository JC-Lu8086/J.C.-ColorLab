# 版本记录

项目：JC ColorLab · 作者：**J.C. Lu** · 许可证：MIT

## 0.1.0 alpha — 2026-10-28

### 首次实现

- 原创 3840 × 2160 数字色卡，提供 146 / 376 / 762 / 4978 色块与独立灰阶，使用加宽黑色间隔与相近颜色分散布局。
- 屏幕目标可选 sRGB、Display P3、Adobe RGB (1998)，嵌入对应 ICC，并使用不同定位标记防止配置混淆。
- 以至少 4K、15 英寸笔记本为设计参考，推荐 376 色；762 色保留为高密度选项，4978 色标注为实验模式。
- 屏幕相对校色与成对色卡风格重建两种工作流。
- 基于定位标记的自动识别与逐点手动调整。
- 分离屏幕参考与照片工作域：支持 sRGB、Adobe RGB (1998)、Display P3、ProPhoto RGB 与受限 ACEScg，明确转换、白点与输出约定。
- 自动排除工作域无法表示的参考色，报告记录色块身份、裁切警告和用户拍摄备注。
- 平滑映射、CUBE 输出、含 3D LUT 的实验性 Adobe XMP、可复查报告与图像预览。
- 本地浏览器界面，以及 macOS / Windows 的源码和本机打包流程。
- Windows x64 实验便携包：官方 Python 3.14.10 嵌入式运行时、14 个依赖 wheel 与 LittleCMS 2.19.1 核心 DLL；包含构建清单和许可证，尚未在 Windows 运行。
- MIT 署名、第三方依赖说明、科学边界与使用文档。

### 发布范围

- 首个可运行实验版本，尚未建立跨设备物理色准认证。
- macOS 开发环境当前 157 项自动测试通过；最终安装包启动验证单独记录，不以测试通过代替跨平台运行验证。
- macOS Apple Silicon 为本地开发目标；运行验证不能替代真实相机与测色仪验证。
- **作者仅有 Mac，Windows 尚未实机测试，暂不提供日常维护保证。**
- Intel Mac 未验证；rawpy 新版的二进制平台支持需单独核对。
- XMP 尚未完成 Adobe 宿主导入与渲染一致性验证。
- XMP 的 ACEScg 模式通过 sRGB 适配表输出，有色域与裁切限制；原生 ACEScg 数值域使用 CUBE。
- 不包含实体品牌色卡的专有参考数据，不生成 DCP 或显示器 ICC。
- 宽色域输出不代表屏幕已准确显示整个色域；ACEScg 仅支持 0–1 SDR LUT 数值范围，不实现完整 ACES/HDR 管线。

未来计划见 [ROADMAP](docs/ROADMAP.md)。
